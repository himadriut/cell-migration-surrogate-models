# Probabilistic Surrogates for Cell Migration

This repository develops neural and hybrid surrogate models for a phenotype-aware mechanistic model of cancer-cell migration under interstitial flow.

The project asks two related questions:

1. Can probabilistic neural networks reproduce the one-step transition statistics of a stochastic mechanistic cell model?
2. Which physical constraints must be retained to obtain stable, biologically meaningful long rollouts?

![Structured hybrid validation](figures/hybrid_colony_validation.png)

## Main result

The unconstrained probabilistic multilayer perceptron was accurate for one-step prediction, but small velocity bias accumulated during recursive rollout. A structured hybrid model that retained the known active-velocity and position-update equations while learning phenotype transitions and short-range cell-cell forces reproduced final colony observables within approximately 0.4% of the mechanistic reference.

The hybrid did not provide a runtime advantage over the optimized vectorized analytical implementation for this small system: it was approximately 8.9% slower. The result demonstrates that a neural surrogate must be compared with a strong optimized baseline and should be used where flexibility, differentiability, or replacement of genuinely expensive physics justifies it.

## Models

| Component | Intended use | Outcome |
|---|---|---|
| Probabilistic MLP | One-step displacement and velocity distributions | Accurate and well calibrated; not stable as an unconstrained recursive simulator |
| Structured transition head | Amoeboid-mesenchymal switching | Reproduced learned flow-dependent equilibrium fractions |
| Transformer | History-based prediction | Improved displacement RMSE by about 24% and velocity RMSE by about 58% over a history baseline |
| Pair-force MLP | Phenotype-dependent short-range interactions | R-squared 0.99974; about 5% colony-force error |
| Structured hybrid surrogate | Long colony rollout | Final observables within about 0.4% of the mechanistic reference |

## Running the notebook

Open `surrogate_digital_twin.ipynb`.

- The notebook retains the original training outputs so the scientific workflow can be reviewed without retraining.
- `Restart Kernel and Run All Cells` retrains the networks and can take several minutes on a CPU.
- Fixed random seeds are used, but small numerical differences can occur across PyTorch and operating-system versions.
- Generated tables and figures are written to `outputs/` and `figures/` when the relevant save cells are run.

## Checkpoints

Trained `.pt` checkpoints are intentionally excluded from the repository. They are generated by the notebook and ignored by Git because binary checkpoints are not required to inspect or reproduce the methodology. If checkpoints are distributed later, use a versioned GitHub Release or an archival repository and publish SHA-256 checksums.

## Validation summary

For the final 1,000-step colony benchmark:

| Condition | Observable | Relative error of hybrid |
|---|---|---:|
| No flow | Final mesenchymal fraction | 0.00% |
| No flow | Final MSD | -0.02% |
| No flow | Final mean speed | 0.00% |
| No flow | Final colony radius | approximately 0.00% |
| No flow | Final nearest-neighbor distance | -0.20% |
| Flow | Final mesenchymal fraction | 0.00% |
| Flow | Final MSD | 0.10% |
| Flow | Final mean speed | 0.00% |
| Flow | Final colony radius | 0.06% |
| Flow | Final nearest-neighbor distance | -0.36% |

The final minimum separation remained equal to the cell diameter, confirming enforcement of excluded volume.

## Scientific interpretation

This repository supports three conclusions:

1. One-step probabilistic accuracy is insufficient evidence of stable long-horizon behavior.
2. Known stochastic and kinematic structure can prevent compounding rollout error.
3. Neural surrogates should be benchmarked against optimized analytical implementations, not only slow nested-loop code.

## Scope and limitations

- The surrogate is trained on synthetic transitions generated by a mechanistic teacher model.
- It is not independently validated on the original experimental cell tracks.
- The close agreement of the structured hybrid partly reflects its deliberate retention of the mechanistic velocity and position equations.
- The present learned pair-force model is useful as a controlled demonstration; the analytical vectorized force remains faster for the current low-dimensional interaction law.

## Related project

This work extends the mechanistic digital-twin project for phenotype-aware cell migration under interstitial flow. The digital twin focuses on state estimation, latent phenotype inference, uncertainty, and forecasting; this repository focuses on learned transition operators and stable surrogate rollouts.
